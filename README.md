# StockPilot-AI-Inventory-Tracker-Management
StockPilot AI is an inventory system for retailers that ingests POS sales, tracks stock, and automates reordering. It pairs a deterministic forecasting engine—calculating demand, safety stock, and stockout dates—with Amazon Bedrock to generate clear owner memos. Built with Flask, RDS MySQL, and EventBridge, it prevents AI hallucinations.
